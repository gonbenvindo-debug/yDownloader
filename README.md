# yDownloader

Adiciona ao YouTube um botão para descarregar vídeos na resolução escolhida.

## Instalação

1. Descarrega e extrai o ZIP do repositório.
2. Abre `chrome://extensions` ou `brave://extensions` e ativa o modo de programador.
3. Escolhe **Carregar expandida** e seleciona a pasta `extension`.
4. Inicia o yDownloader com `npm start` antes de descarregar vídeos.

Requer Node.js 22 ou superior e FFmpeg instalado.
